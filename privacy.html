隱私與資料使用說明

更新日期：2026 年 11 月 23 日

適用範圍

本說明適用於 SEO Data System 本機應用程式及其 Google 資料串接功能。這個公開網站僅提供工具與資料用途說明，不會展示使用者的工作台、網站成效、試算表內容或登入憑證。

存取哪些 Google 資料

  • Google Search Console：使用者可存取的網站清單、搜尋成效、每日及期間數據、查詢與頁面成效，以及 URL 收錄觀測。
  • Google Analytics 4：使用者可存取的帳戶與資源基本清單，以及網站自然搜尋相關的工作階段、活躍使用者、互動及到達網頁報表。
  • Google Sheets：使用者指定試算表的分頁資訊與儲存格數值，用來讀取人工維護的轉換數據及其他已設定欄位。
  • 授權憑證：Google 核發的存取與續期憑證，用於維持使用者同意的資料讀取權限。

應用程式僅要求上述服務的唯讀權限，不以這些權限修改 Google Search Console、Google Analytics 或 Google Sheets 的原始資料。

為何使用這些資料

資料僅用於使用者要求的網站成效查詢、期間比較、歷史追蹤、來源診斷、規則式分析、報表匯出及備份。不同來源保持來源與時間資訊；未取得的值不冒充已確認的零值。

保存與保護方式

應用程式的正式歷史資料保存於使用者電腦的本機資料庫，登入憑證另行保存於本機憑證檔案。資料庫匯出與一般資料庫備份不包含 OAuth 憑證。

應用程式不預設定期清除歷史資料。使用者負責其電腦存取權、備份位置及匯出檔案的管理。若使用者自行指定外部備份或同步資料夾，該副本亦受相應服務與使用者設定管理。

分享與限制用途

本工具不出售 Google 使用者資料，不使用資料進行廣告投放，也不將其用於訓練通用人工智慧模型。應用程式不會自動把 Google 資料公開於此說明網站。

使用者自行選擇匯出、分享，或透過其他工具處理資料時，應另行確認接收對象與相關服務的資料處理方式。除使用者主動選擇、必要安全處理或適用法規要求外，本工具不主動向第三方揭露資料。

SEO Data System 對 Google API 所取得資訊的使用與轉移，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

撤銷授權與刪除資料

使用者可透過 Google 帳戶的第三方連線設定撤銷本工具存取權。撤銷後，工具無法繼續取得新資料；已保存的本機歷史不會因此自動刪除。

如需移除已保存資料，使用者可停止應用程式後，管理或刪除本機資料庫、備份、匯出檔案及憑證檔案；如有外部同步副本，亦需在相應位置處理。若有疑問，可透過下列信箱聯絡。
